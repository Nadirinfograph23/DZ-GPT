---
name: Generated data during dev
description: سلوك ملفات البيانات المحلية أثناء تشغيل Workflow
---

تشغيل Workflow قد يحدّث ملفات cache أو فهارس JSON محلية كأثر جانبي، حتى عندما لا يتغير الكود المطلوب.

**Why:** هذه التغييرات قد تدخل عرضاً في Commit التنظيف أو تجعل الفرع يبدو غير نظيف، وتزيد حجم النشر بلا فائدة.

**How to apply:** افحص `git diff` بعد إعادة تشغيل Workflow وقبل `scripts/deploy.py`، واحتفظ فقط بالملفات المرتبطة بالمهمة الحالية.
